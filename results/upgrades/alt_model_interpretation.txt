  What the agreement test can detect: a weaker model keeps a shared-motif (residual) label automatically
  unless it falsely fires the positional rule or gate+contamination rule; a failing label is lost only if the
  model SOLVES the task. The informative model-dependent checks are the positional rule on the 14 non-splice
  tasks, the splice rescue, and the Route-3 readouts.
  How the contamination label is decided: contamination requires BOTH the model-free TATA gate AND a model-
  dependent Route-3 effect. The gate is positive on 4 binary tasks (alt_model_gate.csv: nontata_prom, enh_ensembl, enh_cohn, nt_enhancers).
  On the gate-negative control the gate blocks a false label where the equalized-MCC collapse also fires (EBM, EBM-512, EBM-pos, LR-ext; EBM-512/EBM-pos inherit the EBM's equalized arms).
  Among gate-positive FAILING tasks the model-dependent half decides contamination vs shared-motif; the rule-3
  variants differ there. enh_ensembl labelled contamination under: primary (equalized collapse) -> no model; sensitivity (composition fraction) -> EBM, EBM-512, EBM-pos; post hoc overlap -> no model.
  nontata_prom (gate-positive; failing only where the model does not solve it) labelled contamination under: primary -> no model; sensitivity -> EBM, EBM-pos; bibm -> EBM, EBM-pos; post hoc overlap -> EBM, EBM-pos.
  Under the bibm map contamination = failing + gate, so a BIBM label changes whenever a weaker model fails a
  gate-positive solved task: BIBM labels are NOT classifier-free.
  CAVEAT for cross-model overlap shares: the EBM receives the 20-d composition signature as explicit inputs, so a
  larger EBM share (e.g. nontata, [3c']) partly reflects that design, not only the dataset.
